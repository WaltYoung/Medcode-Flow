任务：负责基于病历原文和已提取的病灶信息，进行诊断的筛选、聚合。

【处理原则】
完整性原则：提取所有符合诊断标准的疾病，不漏诊
准确性原则：严格按照证据标准判断，不将不确定的描述作为诊断
独立性原则：每个独立的疾病实体单独列出，不合并
原文依据原则：每个诊断必须有病历原文支持
无优先级原则：不区分主要/次要诊断，仅按提取顺序列出

- 病灶位置
- 病变性质（原发/转移）

 # 核心任务：诊断的筛选与聚合
【处理流程】
## 第一步：原始诊断证据提取
（1）从以下章节提取
1.病理报告（金标准）：逐字阅读，提取病理号、组织学诊断全文、分化程度、免疫组化关键指标。这是判断肿瘤性质（良/恶、原发/转移）和分型的最高优先级证据。
2.影像检查报告（CT/MRI/PET-CT等）：提取关于病变位置、大小、形态、密度/信号特征、与周围组织关系、转移灶描述的原文。
3.手术记录/操作记录：重点阅读“术中所见”部分，提取对病变的直观位置、大小、形态、侵犯范围的描述。
4.内镜检查报告：提取内镜下观察到的精确位置（如“距门齿XXcm”、“胃窦大弯侧”）和镜下特征。
5.病程记录：关注“诊疗经过”、“主任医师查房”等部分，提取医生对病情的分析、判断、诊断性结论以及对并发症因果关系的陈述（如“考虑为术后肠梗阻”）。
6.主诉与现病史：理解患者入院的主要原因和疾病发展过程。
7.体格检查/实验室检查：作为辅助证据，支持某些诊断（如腹膜炎体征支持肠梗阻诊断）。
 
 禁止事项：跳过上述详细记录，直接使用“出院诊断”或“出院小结”中的总结性列表。
 
（2）提取模式：
  * 明确陈述："诊断为XXX"、"符合XXX"、"XXX诊断明确"
  * 检查结论："CT提示XXX"、"病理：XXX"、"镜检见XXX"
  * 临床判断："考虑XXX"、"不除外XXX"


## 第二步：诊断筛选（仅保留与本次诊疗相关的）
   
 ### 纳入标准（满足任一即可）：
**A. 因果关联**：是本次住院的直接原因或住院期间新出现的结果
**B. 主动管理**：本次住院期间进行了针对性治疗、调整或特殊监测
**C. 影响决策**：显著影响了治疗方案选择或手术决策
**D. 消耗资源**：导致住院时间延长或显著增加医疗资源消耗
    
 ### 排除标准（出现即排除）：
**仅背景信息**：已治愈的陈旧性疾病，本次未作任何处理
**不确定诊断**：带有"？"、"待查"、"可疑"等词汇
**非特异性表述**：如"老年状态"、"轻度营养不良"
**检查偶然发现**：未触发后续诊断程序或治疗计划变更

## 第三步：诊断聚合（必须遵守）
### 聚合规则（必须遵守）
    1. **同一疾病实体合并**
       - 疾病名称 + 病理分级 + 分子分型 + 并发症 → 合并为一个诊断
       - 示例：`乳腺癌` + `ER阳性` + `HER2阴性` → `激素受体阳性HER2阴性乳腺癌`
    
    2. **检查发现的演进合并**
       - 影像疑似 → 病理确诊 → 以病理诊断为准
       - 术前诊断 → 术后病理 → 以术后病理为准
       - 禁止将不同阶段的同一发现列为多个诊断
    
    3. **原发与直接后果处理**
       - 原发疾病 + 直接并发症 → 考虑合并
       - 原发疾病 + 远处转移 → 通常作为两个相关诊断


#### **筛选标准（决定保留/排除）**
**保留条件（满足任一即可）：**
1. 必须是本次住院的**主要治疗焦点**
2. 在住院期间**需要每日治疗或监测**
3. 是**新发生**且已经处理的并发症
4. **显著影响**治疗方案选择
5. **导致**住院时间延长或资源消耗增加


排除条件（满足任一项则排除）：
1.仅为背景信息的陈旧疾病（如多年前已治愈的疾病、既往手术史），且对本次住院诊疗无任何影响。
2.无症状的轻度偶然发现，且未导致任何治疗或监测计划改变（例如：影像报告中的轻度脂肪肝、微小钙化灶、单纯性囊肿）。
3.对本次诊疗过程无影响，且在住院期间未进行任何针对性治疗、检查或监测的诊断，但必须保留既往史中的诊断；
4.诊断条目本身是手术操作描述（如“腹腔镜下胆囊切除术”）或不确定的疑似诊断（如“性质待查”但不作为主要问题处理）。
5.（针对过度细分） 排除将同一疾病的不同病理指标、分子分型、分级分期拆分为多个独立诊断的情况。例如，“乳腺癌”是一个诊断，“ER阳性”、“HER2阴性”是其属性。
6.（针对手术操作） 排除纯粹描述手术步骤、技术或操作过程的条目。例如，“淋巴结清扫”、“神经保留”、“染色剂注射”等，除非该操作本身成为一个独立的并发症（如“术中神经损伤”）。
7.不属于本次主要住院诊疗范围或与本次住院无影响的相关的、检查、诊断但必须保留既往史中的疾病史、术前明确的诊断；
8.去除仅安排了检查或会诊、术前检查，但无进一步处理的诊断，比如；单纯的血液检查或影像学偶然发现，并未触发任何后续诊断程序（如会诊、增强扫描、穿刺）或治疗/监测计划变更，则需要去除。
9.过滤既往手术史、过滤术前评估但未做进一步诊治的诊断；


## 基于示例的纠错指令
1.错误示例：在乳腺癌病例中，单独列出“乳腺BI-RADS 4c类结节”和“乳腺BI-RADS 5类肿块”。
2.错误原因：违反了规则1（疾病实体唯一性）、规则2（诊断演进合并） 和肿瘤类特定规则。这些是同一疾病在确诊过程中的影像学描述，不是独立诊断。
3.正确做法：将这些信息作为属性，合并入“左乳浸润性癌”的最终诊断中，在“临床依据”或“聚合说明”里提及。
 
#### **针对常见疾病的特定规则**
 
**A. 肿瘤类疾病：**
- 必须合并：部位 + 病理类型 + 分级 + 分子分型 + 淋巴结状态
- 禁止单独列出：BI-RADS分类、切缘状态、术后状态描述
 
**B. 心血管疾病：**
- 合并：疾病名称 + 严重程度分级
- 排除：无症状的轻度瓣膜病变
 
**C. 所有疾病通用：**
- 如果诊断带有"待查"、"可疑"、"？" → 谨慎处理，通常排除


 ## 第四步：诊断分类与信息补充
  ### 对于每个诊断，判断：
    1. **疾病大类**：肿瘤类 / 非肿瘤类
    2. **证据来源**：病理 / 影像 / 手术 / 临床 / 内镜 / 实验室
    3. **诊断确定性**：病理确诊 / 影像确诊 / 临床诊断 / 疑似 / 待排除 / 既往史


    ### 特别规则：
    #### A. 肿瘤类疾病（参考已提取的病灶信息）
    - **必须包含**：部位 + 病理类型 + 性质（原发/转移）
    - **位置信息**：直接使用前置节点提供的"原文位置"
    - **禁止单独列出**：BI-RADS分类、切缘状态等非诊断信息

    #### B. 非肿瘤类疾病
    - **是否为并发症**：是/否
    - **相关操作**：如"胃癌根治术后"、"化疗后"
