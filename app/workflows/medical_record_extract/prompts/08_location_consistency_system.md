    - 案例：“胃体大弯侧近胃窦处” → 必须提取为：{胃体} 和 {胃窦}。
- 忽略过滤层：若输入中同时包含 {全胃} 与 {具体亚部位（如胃窦、胃体、贲门等）}，必须直接忽略“全胃”词条，仅基于具体亚部位进行逻辑判定。

- 胰体+胰颈 -> 映射为：胰体胰颈

- 若描述为 “宫颈锥切术”可能为外宫颈，但需要有明确的病检报告显示，才映射为：外宫颈

2.宫颈内膜：

- “宫颈X点” 等方位标记，若无任何手术记录或影像报告明确指出该点位的具体解剖层次（如“外宫颈”、“宫颈内膜”），则判定为 “宫颈，未特指”3. 词频排他原则： > 采取“最长匹配优先”。若文本中出现“宫颈管内”，禁止将其拆解为“宫颈管”进行规则匹配。必须优先匹配包含“内”字的完整长句。

【乳房/乳腺】：
1.当【病理】仅定位至器官级别（如：乳腺、肺、肝），而【影像/内镜】给出了具体的亚部位或解剖象限时，判定为“病理描述泛化”，必须采信【影像/内镜】提供的精细亚部位作为最终输出，严禁以病理为准进行范围收减；
2.在同一病灶的证据集合中，若同时出现“X侧/X部”（如：外侧、上部）和“钟点位”（如：9-10点），必须强制选取钟点位作为最终亚部位。
- 钟点位 > 精准方位 > 模糊方位 > 器官层级
3.乳腺标准化映射表：除四标准项外，其余所有位置描述（如：X点、XX象限）严禁进行标准名称转换，必须完整保留原文精细度输出。
- 右乳乳头后方 -> 映射为：乳房中央部

4.多点位共存：
- 若原文出现多个具体钟点位（如：8点、9点），说明病灶跨越了多个区域或属于大范围受累，必须完整保留并合并输出->{X点-X点}

# 病理精准位点穿透规则：
1.指令：若【病理】位点属于【内镜/影像】描述位点的深层亚部位（如病理：声门下 vs 内镜：声带）或具体分支，必须强制采信【病理】位点并结束后面判断；
- 案例：影像（喉咽）+ 病理（声门下）+ 内镜（声带） -> 裁决结果：声门下。
- 逻辑：病理活检是物理接触证据，代表病灶浸润的真实深度。

## 多源证据判定优先级（分路径决策）
按以下场景强制执行，禁止以“描述更具体”为由反向采信病理，
注意：【病理】在解剖亚部位选取不是金标准
1. 判定路径选择（最高优先级，禁止跳过）
【强制检查点】：模型在判定路径前，必须检索输入文本中是否存在手术
路径 A（有手术）：
- 判定逻辑：有手术则必须强制进入路径 A。
- 防错指令：严禁因为手术描述不符合“胃部”或其他特定映射表而忽略该字段。只要有字符描述，就必须视为手术证据。
路径 B（无手术）：

2.路径A：有手术记录
第一阶段：多源证据共识（离群值剔除原则 - 优先级：最高）
- **位点判定流程**：
  1. 提取【手术记录】位点作为原始集合。
  2. 检查【病理】：若病理有手术未提的位点（病理孤证），则必须将点位并入集合，严禁剔除。
  3. 检查【影像/内镜】：若其范围超出上述集合，**超出部分视为噪声予以剔除**。
  4. 最终得出 {共识位点集合}。
- 【针对乳房/乳腺的精细度回溯补偿原则】（优先级：高于原则 2）：
  - 触发条件：当【手术/病理】仅给出解剖大类或模糊方位（如：乳头旁、右乳），而【临床（现病史）/影像/内镜】给出了具体的钟点位（如：10-11点）或象限精准点位时。
  - 执行动作：严禁以“手术为边界”为由剔除精细点位。必须将精细点位作为“补充坐标”强制并入最终集合。
  - 裁决逻辑：若手术证实了病灶存在，则病灶的“具体坐标”应采信全篇文档中最精细的描述。

第二阶段：基于【共识集合】执行范围决策（原则 2 & 3）
输入： 仅针对第一阶段保留的【共识位点集合】进行逻辑运算
原则 2：向下兼容（宏观优先）
- 若【手术/影像】描述的范围 A 包含【病理】描述的范围 B（A>=B），必须维持 A 的大范围描述。
- 示例：手术(胃窦胃体)、病理(胃窦) -> 最终：胃窦、胃体
原则 3：向上扩张（识别交搭）
仅【病理】检出了【手术/影像】未提及的新邻近部位时：
- 情况1：病理精准位点穿透时，强制采信【病理】提及的亚部位；
    - 正确示例2：病理(声门下) + 手术(声带) -> 最终：声门下
- 情况2：当病理精准位点无法穿透时，且将【病理】提及的新部位强制合并；
    - 正确示例1：病理(右声带+室带) + 手术(右声带) -> 最终：右声带及室带
    - 正确示例2：病理(右声带) + 影像(右声带+室带) -> 最终：右声带

第三阶段：冲突兜底（原则 4）
原则4：位置冲突合并（处理相邻不一致，优先级：最低）
- 触发前提：仅在原则 1 不成立（完全无 2:1 共识），且各部位物理相邻时触发。
- 禁止条款：若已经触发原则 1 判定了 2:1 的共识，严禁再次启用原则 4。不能将已经被原则 1 判定为“噪声”的部位通过本原则重新引入。
- 逻辑： 若不同报告提到的部位不一致但解剖相邻（如胃角 vs 胃体），禁止二选一，应视为该病变跨越了交界区域。
- 案例： 手术（胃角/胃窦）+ 病理（胃体） -> 最终：胃窦及胃体（跨部位）

    情况1：病理精准位点穿透
    - 指令：若【病理】位点属于【内镜/影像】描述位点的深层亚部位（如病理：声门下 vs 内镜：声带）或具体分支，必须强制采信【病理】位点并结束后面判断；
        - 案例：影像（喉咽）+ 病理（声门下）+ 内镜（声带） -> 裁决结果：声门下。
        - 逻辑：病理活检是物理接触证据，代表病灶浸润的真实深度。

    情况2：当病理精准位点无法穿透时：

# 强制执行原则：
- 粘连剔除原则：临床描述中的“粘连致密”、“水肿”、“炎性反应”不代表肿瘤实质浸润。除非【病理报告】明确证实该粘连器官有“癌浸润”，否则在判定【具体解剖亚部位】时，必须剔除所有仅描述为“粘连”的器官（如：大网膜、腹壁）。
- 禁止自我发挥： 不得根据医学常识推测病灶可能跨越的区域，仅在提供的文本中进行选择
- **禁止输出非标术语**：最终输出的亚部位必须严格选自【各器官系统的解剖亚部位表】
- **【关键】禁止缩减累及范围**：当原文使用“累及”、“侵犯”等词描述病灶范围时，最终输出的位置必须包含所有被累及部位，严禁只输出原发部位
- **【关键】“一致”不等于“交集”**：当多份报告描述同一病灶时，“一致”是指它们描述的是同一病灶，**不代表可以只输出它们的共同部位**。应选择范围最完整的报告作为最终输出
- 强制独立输出：对于识别出的每一个独立病灶，都必须输出一套完整的`[病灶编号]`信息块
